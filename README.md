# POSTLY ✳

사진을 넣고 작은 펀치 머신을 눌러 나만의 빈티지 우표를 만드는 웹사이트입니다.

## 실행 방법

- `index.html`을 브라우저로 열면 사용할 수 있습니다.
- 별도의 설치, 서버, 데이터베이스, API 키가 필요하지 않습니다.

## GitHub Pages 배포 방법

1. GitHub에서 새 **Public** 저장소를 만듭니다.
2. 이 폴더의 `index.html`과 `README.md`를 저장소 최상위(루트)에 업로드합니다.
3. 저장소의 **Settings → Pages**로 이동합니다.
4. **Build and deployment**의 Source를 **Deploy from a branch**로 선택합니다.
5. Branch를 **main**, 폴더를 **/(root)**로 설정하고 **Save**합니다.
6. 배포가 완료되면 표시되는 GitHub Pages 주소에서 사이트를 확인합니다.

## 기능

- 사진 업로드, 위치 조절, 확대/축소
- 원본/빈티지/페이드 사진 필터
- 우표 문구·숫자·컬러 및 펀치 머신 컬러 설정
- 우표 펀칭 애니메이션과 효과음
- PNG / JPEG 저장
- 모바일 반응형 레이아웃

사진은 이용자의 브라우저에서 처리되며 서버에 업로드되지 않습니다.
